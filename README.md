# DevOps Web Deployment

Proyek pembelajaran deployment website menggunakan Ubuntu Server,
Nginx, HTML, CSS, Python, dan Flask API.

## Teknologi
- Ubuntu Server
- Nginx
- HTML dan CSS
- Python dan Flask
- Git

## Fitur
- Halaman website statis
- Backend API untuk memeriksa status aplikasi
- Nginx sebagai web server dan reverse proxy

## API Endpoint
GET /api/status

## Catatan
Proyek ini merupakan proyek pembelajaran pribadi.
Docker dan CI/CD akan ditambahkan pada tahap berikutnya.
